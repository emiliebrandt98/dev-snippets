# DevSnippets
DevSnippets ist eine webbasierte Entwickler-Wissensdatenbank, die es dir ermöglicht, wichtige Code-Schnipsel, nützliche Befehle und "Today I Learned"-Notizen zentral zu speichern, zu organisieren und blitzschnell wiederzufinden.
Anstatt Code-Snippets in unübersichtlichen Textdateien oder Bookmarks zu verlieren, bietet DevSnippets eine saubere Oberfläche mit Syntax Highlighting, Kategorisierung nach Programmiersprachen und einer flexiblen Such- und Filterfunktion.

## 🚀 Features

**Main Features**
- Database Connection: Set up MongoDB connection and data models.
- Snippets List: Browse a well-organised collection of snippets.
- Snippet Details: View detailed information about each snippet.
- Create Snippet: Add new snippets, enriching the snippet catalogue.
- Update Snippet: Update and modify existing snippets.
- Delete Snippets: Remove outdated or unwanted snippets.
- Login: Privat view of your own Snippets.

**Additional Features**
- Copy-to-Clipboard: Save information for a short time.
- Syntax-Highlights: For a better view and understanding of code Snippets.
- Snippets Search: Find code Snippets easy and fast.
- Snippets Filter: Filter for a better overview of Snippets.
- Favorite Snippets: Save favorite Snippets inside a separate list.
- ProfilPage: Change login data and view a small statistic.
- Public/Private Toggle: Share a Snippet with someone else.
- Import/Export of CVS: Import/Export a bigger list of Snippets easyly.
